=====================
LicheePi V3S 相关介绍
=====================

-----------------
LicheePi V3S 是一款基于 Allwinner V3S SoC 的单板计算机，具有低功耗和高性能的特点。它适用于各种嵌入式应用，如物联网、智能家居和边缘计算等。
该板载了丰富的接口和外设，支持多种操作系统和开发环境，方便开发者进行快速原型设计和应用开发。
-----------------

----------
烧录uboot
----------
#.  克隆xfel工具,并在linux系统下构建
#.  构建uboot程序并获得uboot.fex产物
#.  烧录命令：
    ```bash
    ./xfel spinand splwrite 1024 flash_address ./uboot_path
    ```
#.  烧录完成后，使用串口工具连接LicheePi V3S的串口，设置波特率为115200，查看uboot启动信息
#.  如果uboot启动正常，说明烧录成功
#.  如果uboot启动不正常，可能是烧录失败或者uboot.fex文件损坏，请重新烧录
